# Architecture Decision Records

Short documents capturing a decision, its context, and its consequences.

Write one when a choice would be expensive to reverse or when a future reader
would reasonably ask "why is it like this?". Do not write one for routine
choices.

Never edit an accepted ADR to change the decision — supersede it with a new one
and link them. The record of what was believed at the time is the point.

Format: Context · Decision · Consequences · Alternatives considered.
